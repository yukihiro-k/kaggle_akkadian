# kaggle_akkadian

Code for Akkadian-to-English translation experiments related to the Deep Past Initiative machine translation challenge on Kaggle.

## Contents

- `355by*.py`: ensemble / MBR inference variants
- `byt5_train*.py`: ByT5 fine-tuning scripts
- `byt5_inference.py`: ByT5 inference pipeline
- `exp*.py`: experiment-specific decoding variants

## Notes

- The scripts are written for Kaggle-style paths under `/kaggle/input` and `/kaggle/working`.
- Model weights and competition datasets are not included in this repository.
